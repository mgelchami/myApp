# mostapha.

Tech, made clear.

One-page bilingual (English / Arabic) website for mostapha., a security-first Microsoft 365, Cloud and AI specialist.

- `index.html`: the whole site (no build step)
- Edit your LinkedIn link and email in the `CONTACT` line near the bottom of `index.html`
- Add `#ar` to the URL to open it in Arabic

Published with GitHub Pages at https://mgelchami.github.io/myApp/mostapha/ (copied into the web build by `.github/workflows/deploy-pages.yml`).
